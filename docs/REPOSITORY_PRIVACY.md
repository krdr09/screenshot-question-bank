# 仓库范围与隐私

本仓库保存可运行项目的源码快照，包括后端、数据库迁移、前端、自动化测试、依赖锁定文件及 Windows 脚本。它不是用户数据备份。

## 不包含的内容

- 真实截图、私人题目、完整 OCR、逐题真值和题库数据库。
- 图片裁切、练习记录、备份 ZIP、日志、测试运行产物和已安装依赖。
- 原始需求文档、内部设计/计划/交接/故障记录及助手工作目录。
- 原本地仓库的提交历史、个人邮箱、个人工作目录和文件元数据。

初次发布采用独立的根提交，提交作者和提交者使用 GitHub noreply 邮箱。原本地仓库与私人资料继续保留在本机，不会被此快照替换。

## 后续提交

提交前检查 `git status` 与暂存内容，并确认本仓库的 Git 作者邮箱使用 GitHub 的隐私邮箱。`.gitignore` 不能删除已经提交过的内容，也不能自动清理历史。

测试中出现的 `alice`、`local.test`、`server-secret` 等文本属于合成测试输入，用于验证路径及凭据脱敏，不是实际用户信息或有效凭据。

本项目采用 [MIT 许可证](../LICENSE)，版权署名使用 GitHub 用户名 `krdr09`，不包含真实姓名或个人邮箱。第三方依赖仍适用各自的许可证，用户导入的题库、截图等资料不因本项目许可而取得授权。

## 检查边界

发布检查覆盖文件清单、UTF-8 文本、个人标识、常见联系信息和凭据格式、秘密扫描、外部链接、Git 作者/提交者和新提交历史。自动扫描不能证明绝对不存在任何可识别信息；后续加入新文件或开放访问前应重新检查。
