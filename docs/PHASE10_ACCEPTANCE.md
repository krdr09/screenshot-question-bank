# 阶段 10 验收摘要

本文是原本地验收记录的整理版，只保留功能边界与结论。原始日志、截图、工作目录、进程信息及详细开发记录不随源码上传。这里描述的是历史验收，不能替代当前环境重新运行测试。

## 验收范围

使用生产前端、真实 FastAPI、SQLite/Alembic 和后台 worker；自动化业务场景只替换 OCR 引擎，使用程序生成的合成截图。

| 场景 | 覆盖内容 |
| --- | --- |
| A | 图片导入、题库入库、练习作答与后端判分 |
| B | 缺答案题目的人工审核与入库 |
| C | 跨截图题目合并、裁切图和来源图展示 |
| D | 不同批次中相同来源题号的隔离 |
| E | 完整备份、校验、恢复、重启及恢复后的练习 |

历史记录包含上述业务场景通过的结果，并记录了 Windows 安装和启动脚本、真实 CPU OCR 安装自检、后台任务、进程退出和受控目录清理的验证。

## 重新运行

后端和前端测试、生产构建以及 Playwright 场景命令见根目录 README。Windows 脚本检查使用：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\verify-windows.ps1 -Mode Check
```

`-Mode Full` 会从已提交文件创建隔离副本并实际安装、识别、构建和启动，应预留运行时间和依赖下载条件。未提交的文件不会进入这项验证。

## 限制

阶段 10 的业务场景使用合成输入，不能据此声称真实截图的 OCR 准确率。固定真实截图的历史验证范围见 [阶段 11 验收摘要](PHASE11_ACCEPTANCE.md)。
